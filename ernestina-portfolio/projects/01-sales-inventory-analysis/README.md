# Project 01: Sales & Inventory Analysis

## Overview
This project analyzes sales and inventory data to identify patterns, detect anomalies in stock movement, and generate actionable recommendations for better inventory management.

**Business Context**  
Inspired by real operational challenges in retail/wholesale environments where discrepancies between expected and actual stock levels create inefficiencies.

## Objectives
- Clean and prepare sales and inventory datasets
- Perform exploratory data analysis (EDA)
- Identify trends and anomalies in stock inflows/outflows
- Provide data-driven recommendations

## Tools Used
- Python (pandas, matplotlib, seaborn)
- Jupyter Notebook
- Microsoft Excel (for initial exploration)
